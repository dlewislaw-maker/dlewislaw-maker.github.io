Privacy Policy: SyncBack Drive Backup

Effective October 19, 2026

What this application is

SyncBack Drive Backup is a private Google OAuth client used only by its owner, Derik Lewis, so that the owner's own copy of SyncBackPro desktop software can back up files from the owner's computer to the owner's own Google Drive account.

Google data accessed

When the owner authorizes it, SyncBackPro requests the owner's Google account email address and basic profile information (to identify the connected account) and access to the owner's Google Drive (to list, create, update and delete backup files in that Drive).

How the data is used

Google user data is used only to perform the backups the owner configures in SyncBackPro on the owner's computer. It is not used for advertising, analytics, profiling or any other purpose.

Storage

Authorization tokens and backup settings are stored by SyncBackPro on the owner's computer. Backed-up files are stored in the owner's Google Drive. The owner does not operate any server or database that receives Google user data, and this website collects nothing.

Sharing

Google user data is not sold, transferred or shared with any third party. Data passes only between the owner's computer and Google's servers.

Retention and deletion

Files remain in the owner's Google Drive until the owner deletes them. Access can be revoked at any time at myaccount.google.com/permissions, and stored tokens are removed by deleting the account link in SyncBackPro.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
